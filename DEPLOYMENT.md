# Мобильная v1.0.1: только локальная проверка

Не загружать в main и не публиковать без отдельного разрешения.
Рабочая копия находится в ветке mobile-v1.0.1. Тестовая сборка — test-build.
Запуск из рабочей копии: node serve-mobile.cjs; открыть http://127.0.0.1:8005/.
Для Wi-Fi используйте адрес локального сервера, указанный в MOBILE_AUDIT.md рабочей копии. Телефон и ноутбук должны быть в одной сети. Настройки брандмауэра автоматически не меняются.
Приложению достаточно обычного статического сервера; все пути относительные. Для будущего размещения копируют содержимое test-build, не тесты и не Git.
Для диагностики только на локальном тестовом сервере добавьте ?audio-debug=1 к URL. Панель покажет загрузку, фактически полученные байты, декодирование и переход к резервному звуку. Диагностический скрипт отсутствует в test-build и не должен попадать в публикацию.
