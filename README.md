# Last-Lantern — release candidate

Тестовая статическая сборка, не опубликована. Откройте index.html локально или отдавайте содержимое папки обычным статическим HTTP-сервером. Сборщик и сервер приложению не нужны; все пути относительные.

Управление: WASD/стрелки, E — фонарь, пробел — вспышка, Esc — пауза. Звук запускается после действия пользователя. Музыка, эффекты и настройки сохранены.

assets/audio/audio-data.js содержит все пять исходных записей без перекодирования, в Base64. Отдельные дубли WAV/OGG и исходный архив набора существ для запуска не нужны и исключены. SHA-256 встроенных записей приведены в assets/audio/manifest.json. Происхождение и CC0: AUDIO_SOURCES.md; пути к отдельным оригиналам в этом документе относятся к рабочему проекту, а не к этой минимальной сборке. Графика рисуется Canvas; шрифты системные.

Перед публикацией остаётся ручная проверка в установленных Chrome/Edge; результаты аудита находятся в RELEASE_AUDIT.md рабочего проекта. Это не утверждение об успешной проверке во всех браузерах.

## Подготовка звука

На первом открытии виден статус загрузки. Если большой аудиопакет не загрузился за 12 секунд или недоступен, игра продолжает работу с резервным синтезатором и предупреждением. При обычной загрузке оригинальные записи заранее декодируются, а воспроизведение начинается только после Start. Для повторной попытки загрузить записи обновите страницу. На медленном соединении резервный звук не эквивалентен принятому записанному саундтреку.


## Мобильная версия (v1.0.1)

Тот же index.html. Устройства только с сенсорным вводом (`(hover: none) and (pointer: coarse)`) получают мобильную презентацию: класс `mobile` на `<html>`, стили mobile.css, модуль mobile.js. Для проверки в обычном браузере добавьте `?mobile` к адресу; `?desktop` принудительно включает настольный режим. Настольная вёрстка (style.css), клавиатура, игровая логика, баланс и карта не изменены.

- Основная игровая ориентация — горизонтальная: карта занимает всю высоту экрана под компактной полосой показателей, джойстик появляется под левым большим пальцем в месте касания, кнопки «Вспышка» и «Зажечь» — справа. Учитываются safe-area (вырез, индикатор «Домой»). В вертикальном положении доступны меню и пауза, игра просит повернуть телефон.
- Звук: мобильная страница не загружает audio-data.js (34 МиБ). Пять записей запрашиваются отдельно из assets/audio/mobile (AAC-копии, затем Ogg-оригиналы) с собственными лимитами времени. Раунд начинается не позже ~2,5 с после нажатия: пока записи не готовы, играет резервный синтезатор, записи подключаются позже. Полный отказ аудио не блокирует игру. На Safari 16.4+ используется Audio Session `playback`, чтобы звук игры был слышен при включённом беззвучном режиме.
- Настройки звука и громкости открываются из карточки меню и паузы. Инженерные сведения о состоянии аудио игроку не показываются.

## Проверки

`npm test` — регрессионные проверки движка, звука и мобильных модулей в Node (без зависимостей). `npm run test:browser` — проверки в реальном Chromium через Playwright (установленный глобально) при запущенном `npm run serve`: раскладка и касания на размерах iPhone, запуск при медленном и недоступном аудио, настольные размеры 1024×768, 1280×720, 1366×768, 1440×900 без прокрутки.
